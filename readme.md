# NLP Basics with NLTK

This repository contains basic Natural Language Processing (NLP) concepts and implementations using Python, NLTK, and Scikit-learn.

The notebook demonstrates different text preprocessing techniques step by step, starting from raw text and converting it into numerical representations.

## 📌 Topics Covered

- NLTK Installation and Setup
- Sentence Tokenization
- Word Tokenization
- Stemming
- Lemmatization
- Stopword Removal
- Regular Expression Text Cleaning
- Text Preprocessing
- Bag of Words (BoW)
- CountVectorizer

## 🛠️ Technologies Used

- Python
- NLTK
- Scikit-learn
- Jupyter Notebook
